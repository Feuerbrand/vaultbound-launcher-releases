# Vaultbound Launcher

Offizielle Windows-Downloads des Vaultbound Minecraft-Launchers.

## Installieren

1. Unter [Releases](https://github.com/Feuerbrand/vaultbound-launcher-releases/releases/latest) die Datei `Vaultbound-Setup-<Version>.exe` herunterladen.
2. Starten und auf **Installieren** klicken. Adminrechte sind nicht nötig, installiert wird nur für dein Windows-Konto.
3. Windows kann beim ersten Start „Unbekannter Herausgeber“ anzeigen. Dann auf **Weitere Informationen → Trotzdem ausführen** klicken.

## Updates

Der Launcher prüft bei jedem Start, ob es eine neue Version gibt, und installiert sie automatisch.

## Deinstallieren

Windows-Einstellungen → Apps → Installierte Apps → **Vaultbound Launcher** → Deinstallieren.
